## Адресное исправление

- Новые записи сохраняют исходный заголовок из кеша кандидатуры даже без
  редакционного изменения: `source.title_original or source.title`.
- Для существующих записей аудитор использует `post.news_director.title_original`
  только при отсутствии верхнего `post.title_original`. Явно сохранённое
  верхнее значение имеет приоритет. Состояние публикации не мигрируется.
- Источник не восстанавливается из `published_row.title_evidence`,
  `body_evidence` или редакционных метаданных внутри самой переводной строки.
  Такие подстановки были бы круговым доказательством.
- Отсутствие `published_row` больше не позволяет обойти финальный контракт.
- Предлагаемая правка подписи повторно проходит контракт до Telegram-вызова.
  Недостающие доказательства не закрываются фиктивным исправлением подписи.
- Возраст публикации и версия издателя по-прежнему ограничивают изменения
  Telegram. Исторические нарушения остаются видимыми, без объявления проверки
  успешной из-за возраста. Правило подсчёта `unresolved` для старых версий
  издателя не менялось.

Пороговые значения, правила сопоставления цитат, требования к доказательствам
каждого абзаца и проверка `assert unresolved == 0` не ослаблены.
