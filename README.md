# SkySakhNews Bot

Автоматический Telegram-публикатор новостей на GitHub Actions.

## Current production

**Version:** `stable-v12.0`

```text
GitHub Actions
  → source collectors
  → strict freshness/direct-link/media filters
  → quality_v12 editorial director
  → category autocorrection
  → semantic Editorial Gate
  → Telegram sendPhoto
  → immediate post-publication watchdog
  → state.json
```

Штатный entrypoint: `src/publisher_v12.py`.

## Editorial policy

Скользящее окно — 20 видимых публикаций:

| Направление | Доля | Публикаций |
|---|---:|---:|
| Сахалин | 30% | 6 |
| Россия: политика и законы | 20% | 4 |
| Россия: экономика и деньги | 20% | 4 |
| Происшествия и безопасность | 15% | 3 |
| Мир / геополитика / мир о России | 10% | 2 |
| IT и технологии | 5% | 1 |

Квота повышает приоритет только среди материалов, прошедших абсолютный порог качества. Слабый материал не публикуется ради заполнения пропорции.

## Mandatory gates

Каждый пост обязан пройти:

- доказанную свежесть не старше 36 часов;
- прямую ссылку на оригинальную статью;
- корректную географию и категорию;
- абсолютный порог общественной значимости;
- проверку заголовка, фактов, чисел и модальности;
- тематическую фотографию исходной статьи;
- дедупликацию URL, заголовка, сюжета и изображения;
- повторный аудит уже отправленного Telegram-сообщения.

Жёстко исключаются календарные материалы, награждения и поздравления, lifestyle/SEO, реклама, сервисные объявления о возврате документов, рядовая дорожная статистика и мягкие мероприятия без общественно значимых последствий.

Если post-publish watchdog обнаруживает ошибку, сообщение удаляется через Telegram Bot API и помечается в `state.json`.

## OpenRouter

OpenRouter не управляет отбором. Детерминированный редактор является основным. Для русскоязычных источников используется проверенный extractive-first режим; OpenRouter нужен в основном для перевода иностранных материалов и необязательной дополнительной проверки. Его отказ не останавливает выпуск.

## Main files

- `src/quality_v12.py` — строгая редакционная политика, категории, значимость и пропорции;
- `src/publisher_v12.py` — production orchestration;
- `src/post_publish_audit_v12.py` — немедленный повторный аудит и удаление ошибки;
- `src/production_selftest_v12.py` — регрессии по фактическим ошибкам ленты;
- `src/quality_audit_v12.py` — dry-аудит на живых источниках;
- `V12_LIVE_VERIFIED.json` — аттестация реального выпуска;
- `V12_FEED_CLEANUP.json` — отчёт очистки известных ошибочных публикаций.
