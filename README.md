# SkySakhNews Bot

Полностью автоматический Telegram-публикатор новостей на GitHub Actions. Телефон, Termux, постоянно включённый компьютер и отдельный VPS не требуются.

## Production

Текущая версия: **stable-v10.4**.

Единственный плановый publisher:

```text
.github/workflows/auto_publish_v7.yml
        ↓
src/media_enforced_runner.py
        ↓
src/editorial_gate_runner.py
        ↓
src/production.py
        ↓
src/news_bot_v9.py / src/news_bot_v8.py
        ↓
Telegram Bot API
```

Перед Telegram каждый материал проходит:

```text
источник → свежесть → прямая ссылка → первичная категория
→ title-first category reconciler → source/category pre-gate
→ перевод/редактура → title/source semantic gate
→ проверка фактов, чисел и модальности
→ обязательная фотография из исходной статьи или её RSS
→ устойчивая доставка sendPhoto
```

## Политика медиа и доставки

Каждая опубликованная новость обязана иметь фотографию, полученную непосредственно из исходной статьи или RSS-записи этой новости. Текстовый пост без медиа запрещён.

```text
source photo
    ↓
обычная загрузка JPEG
    ↓ при подтверждённой ошибке
повторное безопасное кодирование JPEG
    ↓
отправка без HTML-разметки подписи
    ↓
передача Telegram прямого source image URL
    ↓
другая пригодная фотография из этой же статьи
    ↓
persistent delivery queue
    ↓
повтор перед свежими новостями в следующем цикле
```

Техническая ошибка `sendPhoto` больше не удаляет и не теряет уже проверенную новость. Материал сохраняется в `pending_media_delivery` вместе с прошедшим Editorial Gate текстом и повторно отправляется в следующих циклах.

Неопределённый сетевой timeout не вызывает немедленную повторную отправку, чтобы не создать дубль: материал безопасно переносится в очередь.

```text
нет безопасного source image → кандидат не допускается
generic/Wikimedia/stock      → запрещено
ошибка sendPhoto             → альтернативные способы доставки
все способы временно недоступны → очередь, а не потеря новости
text-only sendMessage        → запрещён
```

Логотипы, баннеры, заголовочные карточки, заглушки и универсальные тематические иллюстрации не считаются фотографией новости.

## Что проверяется

- новость не старше 36 часов;
- итоговая ссылка ведёт на оригинальную статью, а не на Google News;
- география определяется по смыслу новости, а не по домену СМИ;
- заголовок отражает центральную суть источника;
- `может/планирует/обсуждает` не превращается в `сделал/ввёл/принял`;
- отсутствуют придуманные числа и факты;
- категория соответствует заголовку и статье;
- землетрясение сохраняет имеющиеся в источнике магнитуду, глубину, расстояние, балльность и время;
- одинаковые URL, заголовки, фотографии и сюжетные кластеры не повторяются;
- каждая публикация имеет `with_image=true`, `image_url`, `image_hash` и подтверждённый media origin;
- отложенная новость хранит ранее одобренный Editorial Gate и не проходит бесконтрольный рерайт заново;
- если OpenRouter недоступен, русскоязычная новость может пройти только через дословный extractive fallback; неподтверждённый рерайт не публикуется.

## Потоки

- `📍 Сахалин` — локальные события, ЧП и сейсмика;
- `🌍 Мир о России` — материалы авторитетных мировых СМИ, где Россия является предметом новости;
- `🇷🇺 Россия / безопасность`;
- `🇷🇺 Россия / происшествия`;
- `🇷🇺 Россия / политика`;
- `🇷🇺 Россия / экономика`;
- `🧭 Геополитика`;
- `💻 IT / технологии`.

Отложенные из-за технической доставки материалы обрабатываются первыми. Затем первый свежий пост выпуска выбирается локальным, если существует прошедший все проверки сахалинский кандидат с фотографией. Второй выбирается из другого приоритетного потока и также обязан иметь фотографию.

## Источники

Локальные:

- SakhalinMedia RSS;
- ASTV HTML adapter;
- Sakh.online HTML adapter;
- Sakhalin Google News как discovery-источник с обязательным разрешением прямой ссылки.

Россия и мир:

- Interfax;
- TASS;
- Reuters;
- AP News;
- BBC World;
- The Guardian World;
- BBC Technology;
- The Guardian Technology.

Источник без пригодного собственного изображения в конкретном материале в выпуск не попадает. Это отдельное правило качества контента; технический сбой доставки уже подготовленной фотографии приводит не к исключению, а к повторной доставке.

## Расписание

Сахалин: UTC+11.

```text
07:00
10:00
13:00
16:00
19:00
22:00
```

Cron GitHub Actions:

```text
0 2,5,8,11,20,23 * * *
```

За цикл публикуется до двух материалов. Ноль или один новый пост допустимы, если остальные кандидаты не имеют корректного source image или не прошли редакционный контроль. Технически недоставленный материал остаётся в очереди и имеет приоритет на следующем цикле.

## Secrets

В `Settings → Secrets and variables → Actions`:

- `TELEGRAM_BOT_TOKEN`;
- `TELEGRAM_CHANNEL_ID`;
- `OPENROUTER_API_KEY`;
- `OPENROUTER_MODEL` — необязательно;
- `MEDIA_PENDING_MAX_HOURS` — необязательно, по умолчанию 36;
- `MEDIA_PENDING_MAX_ITEMS` — необязательно, по умолчанию 24.

## Контроль качества

- `production_ci.yml` — компиляция, semantic/media tests и эмуляция отказа Telegram;
- `system_smoke_test.yml` — ручная техническая проверка;
- `state.json` — история публикаций, дедупликация, `pending_media_delivery` и health-status последнего запуска.
